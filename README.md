# 🏋️ Featured Projects

**[Mesocycle Builder](https://github.com/SheridanJustin/mesocycle-builder)**: plan hypertrophy training blocks on a
drag-and-drop board with live weekly volume per muscle group, then log every set with PR badges and personal bests.
*TypeScript · Next.js · React · PostgreSQL · Prisma · Playwright*

**[HexaFit](https://github.com/SheridanJustin/HexaFit-Workout-App)**: a free, bloat-free workout tracking app with
workout templates, set logging, progress tracking and AI gym-machine identification.
